# Features

One MD per feature. File name: `<feature-slug>.md`.

## Template

```markdown
# <Feature Name>

- **Status**: planned | in progress | shipped
- **Work item**: work/todo/NN-<slug>.md
- **Change report**: work/changes/YYYY-MM-DD--<slug>.md

## What it is
## User flow
## Data / API
## Files
## Open questions
```

> Runtime/status tracking belongs in `work/`, not here. This folder documents the feature itself.
