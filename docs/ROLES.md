# Users and roles (MVP §3)

| Role | Works in | Main jobs |
|------|----------|-----------|
| Super admin | Super admin page | Create complexes + owner accounts; activate/deactivate |
| Owner | Everything | Settings, buildings, outlets, staff, prices, weather limits, reports |
| Manager | Assigned outlets | Products, prices, voids, outlet reports |
| Front desk | Hotel, chalets, hut | Reservations, check-in/out, folios, payments |
| Cashier | Restaurants, hut, shop | Orders, payments, charge to room |
| Rental desk | Rental shop | Rent out, returns, damage fees |
| Service staff | Spa, sauna, sports, ski school | Slots, bookings, schedule, guided outing headcount |
| Transport desk | Transport | Shuttles, taxi, pickups, vehicles, drivers |
| Lift operator | Lift stations | Lift status from a phone |

Drivers do **not** log in for MVP. Printed passenger list only.
