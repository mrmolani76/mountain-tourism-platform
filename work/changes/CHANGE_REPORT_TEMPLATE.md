# Change Report Template

File name: `YYYY-MM-DD--<short-description>.md`

```markdown
# Change Report: <Short Title>

- **Date**: YYYY-MM-DD
- **By**: <Name / Agent>
- **Change ID**: <optional>

## 1. Summary
What changed, in one line.

## 2. Before
What existed before — file path, old value/code, etc.

## 3. After
What exists after — file path, new value/code, etc.

## 4. Reason
Why — requirement, bug fix, feature, setup.

## 5. Files Affected
- `path/to/file1`

## 6. Verification / Status
- [ ] Tested / Verified?
- [ ] Migrations/Scripts pending?
- [ ] Notes
```

## Rules
1. Write a report for every change.
2. Write it before declaring done.
3. Before/After must use actual values.
4. Always include Reason.
