# Work Tracking

Kanban folders for agents and humans.

| Folder | Meaning |
|--------|---------|
| `todo/` | Planned |
| `inprogress/` | Active (WIP limit 1) |
| `completed/` | Done |
| `changes/` | Mandatory change reports |
| `bugs/` | Bug reports + INDEX |

Master lists: `PLAN.md`, `SUMMARY.md`.  
Item template: `TEMPLATE.md`.  
Skill: `work-tracker` / `change-report` / `bug-tracker`.
