# Todo Work

An MD file lands here when work is planned but not picked up yet (`status: todo`).

> **Rule**: New work item → create `work/todo/NN-<short-title>.md` from `work/TEMPLATE.md` and add its row to `work/PLAN.md` → `## Todo`.
> Pick up work → move the MD to `work/inprogress/` BEFORE editing.
