# Work Plan — Mountain Tourism Platform (Kanban)

Master list of planned work. Detailed MD for each item lives in `work/todo/` (todo), `work/inprogress/` (in progress) and `work/completed/` (finished).

> **Flow**: On pickup, move the MD `work/todo/ → work/inprogress/` and its row from the **Todo** table to the **In Progress** table. On completion, move it `work/inprogress/ → work/completed/` and its row from **In Progress** to **Completed**. `work/PLAN.md` has three separate tables (Todo / In Progress / Completed), not one — each row always sits in the table that matches the item folder status.

## Status Legend

- `todo` — pending (MD file in `work/todo/`)
- `inprogress` — in progress (MD file in `work/inprogress/`)
- `completed` — done (MD file in `work/completed/`)

> Any item can move back from `inprogress` to `todo` (blocked / delayed) — set Status = `todo`, move the MD to `work/todo/`, move its row from the In Progress table to the Todo table, and fill `## Return to Pending Log` in the MD. Reverse (completed → open) is not allowed — completed stays completed.
