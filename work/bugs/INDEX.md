# Bug Tracker — Master Index

Each confirmed bug has one report file at `work/bugs/BUG-<TYPE>-<NNN>-<short>.md` (template `work/bugs/BUG_REPORT_TEMPLATE.md`). This INDEX is the master backlog — three separate tables; each row **always** sits in the table that matches the bug file `Status`. On status change, move the row between tables (same as `work/PLAN.md`). The `bug-tracker` skill enforces this flow.

Status flow: `BUG_CREATED → BUG → TODO → IN_PROGRESS → BUG_FIX_IN_PROGRESS → RETESTING → VERIFIED → COMPLETED`

| INDEX table | Statuses |
|-------------|----------|
| `## Open` | BUG_CREATED / BUG / TODO / IN_PROGRESS / BUG_FIX_IN_PROGRESS / RETESTING |
| `## Verified` | VERIFIED |
| `## Closed` | COMPLETED |
